# Tamaki Studio-Lite v1.0.0（超軽量高速執筆工房）

筆者（たまきぱずず氏）特有の文体美学（鋭いメタ認知、高い解像度、宇宙世紀原理主義、思考の迷走プロセス、大人の分別と軽妙なオチ）を完全再現する**超軽量・高速執筆支援スタジオ**です。

PC（Mac）のCPU・メモリ負荷を極限まで削減し、**長時間の執筆でも絶対に重くならず快適にサクサク動作**するよう再設計されました。

---

## ⚡ 主な特徴・v4.1.1からの軽量化ポイント

1. **常駐通信・バックグラウンド負荷の完全撤廃**:
   - 動作を重くしていたクラウド同期常時ポーリング（Tamaki Sync 3.0）、QRコード生成ライブラリ、EPUBバイナリ生成などを完全排除。
   - すべての処理を「ボタンを押した時だけ動くオンデマンド処理（イベント駆動）」にすることで、待機時CPU使用率ほぼ0%、メモリ消費を70〜80%削減。
2. **便所の落書き → 各ジャンルへのワンタップ振り分け**:
   - 吐き出した落書きメモをワンタップで「日常エッセイ」「ガンダム論考」「小説・官能」の各専用入力欄へ自動転記＆展開。
3. **右側2画面スタジオ（たたき台 ＆ 執筆・清書エリア）**:
   - **上段（たたき台エリア）**: AI生成ドラフトやプロンプトを出力。「⬇️ 執筆エリアに流し込む」「🔄 全文置換」でスムーズに清書へ移行可能。
   - **下段（執筆エリア）**: メイン原稿エディタ。文字数カウント、読了目安時間、.md保存。
4. **【新設】原稿から推敲用プロンプトを作成**:
   - 執筆エリアの文章とたまきぱずず度チューニングを組み合わせ、筆者特有の視点（メタ認知、解像度、AI臭さ排除、オチ）でリライトするための強力な推敲プロンプトをワンクリック生成。
5. **残された重要機能**:
   - **身バレ置換辞書**: 特定固有名詞をワンクリックでフィクション表現に一括匿名化。
   - **Gemini API設定**: APIキー設定時はスタジオ内で直接AI生成、未設定時はプロンプト生成＆自動コピー。
   - **履歴管理**: 便所の落書き履歴・原稿スナップショットの保存と復元。
   - **安全なバックアップ**: 全データをJSONファイルとして一括書き出し・完全復元。
   - **フル版(v4.1.1)呼び出し導線**: ヘッダーのボタンからいつでもv4.1.1へジャンプ可能。
6. **iPhone 14 Pro (393×852pt) 完全最適化**:
   - 片手親指で操作できるボトムナビ（Thumb Zone）。
   - キーボード直上の「クイック執筆アシストバー（三点リーダー、ダッシュ、かぎ括弧、ルビなど）」。
   - Dynamic Island・セーフエリア調和。

## 🚀 起動・アクセス方法

### 💻 Mac / 📱 iPhone での起動
ターミナルで以下のコマンドを実行します：

```bash
./start_lite_server.sh
```

- **Macブラウザ**: [http://localhost:8088/index.html](http://localhost:8088/index.html)
- **iPhone（同一Wi-Fi）**: ターミナルに表示される `http://[MacのIPアドレス]:8088/index.html` をSafariで開く

※ フル機能版（v4.1.1: ポート8085）と競合せずに独立稼働します。
