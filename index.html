📱 iPhone / スマホでの快適な使い方

Safariの「共有」ボタン →「ホーム画面に追加」を行うと、iPhoneのホーム画面から全画面のネイティブアプリ感覚でいつでも一発起動できます。

✨ 主な機能と使い方のコツ

  • 📄 過去原稿ドロップ: 手持ちの .md / .txt ファイルを放り込むだけで、AIがその文体をお手本として直接模倣。フォームへも一括展開可能。
  • 🧩 語録・思考パレット: 「オールドタイプ原理主義」「安心感を買っているだけ」などの特有フレーズをワンクリックで入力欄へ挿入。
  • 🎯 例文プリセット: 「ガンダム52話打ち切りIF」「テキサスコロニー建造計画」「酷暑ゴルフ散財」などをワンタッチ読込。
  • 📊 シンクロ率チェッカー: 自虐度、五感解像度、改行テンポ、オチのキレをリアルタイム診断。AI特有の綺麗事まとめを自動警告。

🚀 noteへの投稿フロー

  1. 各項目を入力（またはプリセット／原稿読込）
  2. 「AIで筆者風に直接執筆」または「プロンプトを合成・コピー」
  3. 完成文を確認し、「文章をコピー (note用)」を押してnote新規投稿に貼り付け！

📱 iPhoneで Tamaki Studio を開く

同一Wi-Fiに接続したiPhoneのカメラアプリで、以下のQRコードをかざしてください。Safariで即座に起動します。

📲 iPhoneホーム画面に追加してアプリ化する手順
  1. iPhoneの Safari でQRコードのURLを開く
  2. 画面下の 「共有」ボタン（四角から上矢印）をタップ
  3. 「ホーム画面に追加」 をタップ
  4. ホーム画面に専用アイコンが並び、全画面のネイティブアプリとして起動できます！
