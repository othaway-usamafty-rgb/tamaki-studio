# Tamaki Studio v4.1.1（たまきぱずず専属執筆工房）

筆者（たまきぱずず氏）特有の文体・思考様式（鋭いメタ認知、高い解像度、宇宙世紀原理主義、思考の迷走プロセス、生々しい本音、軽妙なオチ）を完全再現するための専用執筆支援Webアプリケーションです。

v4.1.1 アップデートでは、**iPhone 14 Pro（画面幅393px、Dynamic Island、Safari / PWAスタンドアロン対応）に完全最適化**を実施。片手親指での操作領域（Thumb Zone）にジャストフィットするボトムナビ、三点リーダーやルビを即座に挿入できるクイック執筆アシストバー、iOS風ボトムシートモーダル、全画面集中執筆モード（Zen Mode）などを搭載しました。

>
> 📱 **改修・開発ルール**: 本プロジェクトのすべての修正・更新において、**「iPhoneのネット環境（Safari/Chrome、自宅Wi-Fi、4G/5G通信、PWA）で完全に動作すること」**が標準必須仕様として規定・自動化されています。

## 🚀 起動・アクセス方法

### 方法1: Web（GitHub Pages）で開く（おすすめ）
ブラウザで以下にアクセスします：
**[https://othaway-usamafty-rgb.github.io/tamaki-studio/](https://othaway-usamafty-rgb.github.io/tamaki-studio/)**

### 方法2: ローカルWebサーバーで開く
ターミナルで本ディレクトリ（`tamaki-studio`）に移動し、以下のコマンドを実行します：

```bash
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

## 📱 v4.1.1 iPhone 14 Pro 画面最適化アップデート（最新）

iPhone 14 Pro（画面解像度 393 × 852 pt、Dynamic Island、Safari / PWAスタンドアロン）での執筆体験を極限まで引き上げるため、以下の画面最適化を実施しました：

1. **ボトムナビゲーション刷新（親指操作 Thumb Zone 最適化）**:
   * 「⚙️ 設定」「📝 執筆」「☁️ 同期」の3大メインタブが均等配置され、片手親指で自然にタップ可能。
   * エディタ選択中も文字数やシンクロ率がインジケーターとして連動。
2. **iPhone専用「クイック執筆アシストバー」新設**:
   * iPhoneのソフトウェアキーボードでは入力しにくい「三点リーダー（……）」「ダッシュ（――）」「かぎ括弧（「」）」「二重かぎ括弧（『』）」「小説ルビ記法（｜漢字《ルビ》）」をエディタ直上でワンタップ挿入。
   * 「↩ 戻す（Undo）」「📋 コピー」「🔲 集中」も0秒アクセス可能。
3. **iOS風「ボトムシート・モーダル」導入**:
   * 「☁️ 同期」「🎭 身バレ辞書」「📖 Kindle縦書き」「取扱説明書」などのモーダルが、画面下部から滑らかにせり上がるiOSネイティブ風ボトムシートに変形。
   * シート上部のドラッグバーをつかんで下にスワイプするだけで自然に閉じるジェスチャー操作に対応。
4. **Dynamic Island & セーフエリア完全調和**:
   * `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` との重なりを解消。
   * `100dvh`（Dynamic Viewport Height）と `interactive-widget=resizes-content` の採用により、Safariアドレスバー開閉やキーボード表示時のガタつき・意図しないズームを完全防止。
5. **🔲 iPhone全画面集中執筆モード（Zen Mode）**:
   * アシストバーの「🔲 集中」をタップすると、ヘッダー・サイドバー・ナビが非表示となり、iPhone 14 Proの縦長Retina画面を100%活用した原稿執筆に没入可能。

## ✨ v4.1.0 主な新機能と特徴（大人の情愛・心理サスペンス強化）

### 1. 🎭 『鍵』式・独白交代（デュアル・モノローグ）執筆モード
* **2列並列独白レイアウト**: 谷崎潤一郎『鍵』のように、「俺（男性視点）」と「保江（女性視点）」の心理・独白を並列で書き分け。
* **視点別執筆＆ワンタップ入れ替え**: 左右の視点テキスト・名前をワンクリックで入れ替え可能。
* **交互マージ結合**: 2つの独白を時系列に沿って「【俺】…」「【保江】…」と交互に自動結合し、メインエディタへ一括転送。
* **デュアル専用AIプロンプト**: 男女双方の隠された意図・すれ違い・沈黙の駆け引きを際立たせる専用AI執筆支援。

### 2. 🛡️ 官能セーフティ・表現リスク事前検知
* **直接的過激表現のローカル自動検知**: note/Kindle等のコンプライアンス基準に抵触しやすい性的・露骨な表現をリアルタイム警告。
* **文学的五感・心理描写へのワンタップ言い換え**: 「熱を帯びた皮膚」「衣擦れの音」「湿り気を帯びた空気」「吐息の重なり」など、情緒豊かでサスペンスフルな文学的表現へのワンクリック置換サジェストを提供。

### 3. 🎨 五感サンプリング（テクスチャ）パレット
* **あずますくね風テクスチャ語録**: 視覚・聴覚・嗅覚・触感・生理の5カテゴリに分類された語録パレット。
* **ワンタップ挿入**: エディタのカーソル位置へ「微熱を帯びた首筋」「静寂を切り裂く衣擦れ」「かすかな潮の匂い」などを0秒で流し込み、描写の解像度を一気に引き上げます。

### 4. 🔒 カスタム「身バレ置換辞書」管理機能
* **実名・特定情報の完全ガード**: 実名・実在ホテル名・車種・地名などの登録・管理。
* **原稿全体の一括フィクション化**: ボタン一つで原稿内の実在固有名詞を仮名・フィクション表現へ一括置換。
* **インポート/エクスポート**: JSON形式でのバックアップ保存・共有に対応。校正インスペクターとも連動して未置換の固有名詞を自動警告。

### 5. 📖 Kindle（KDP）縦書き原稿・EPUBワンクリック出力
* **縦書きプレビュービューア**: 原稿用紙・文庫本風のリアルタイム縦書きプレビュー（`writing-mode: vertical-rl`）。
* **純JSによる完全ブラウザ完結EPUB3生成**: 外部サーバーやライブラリに一切依存せず、ブラウザ単体で電子書籍標準のEPUB3バイナリ（STORE非圧縮ZIP）を0秒自動生成＆ダウンロード。
* **でんでんコンバーター用Markdown出力**: ルビ・圏点・見出しに対応したでんでん記法テキストの即時書き出し。

### 6. 🚽「便所の落書き」自動履歴保存とバックアップ強化
* **自意識デトックスの自動退避**: デトックス入力エリアから離れる、またはAI送信するタイミングで過去30件を自動アーカイブ。
* **過去落書きの即時復元**: ドロップダウンから日時付きで過去の閃き・感情の吐露をワンタップで呼び出し可能。

### 7. 🔄「Tamaki Sync 3.1」オフライン保護と同期ステータス可視化
* **3色同期ステータスバッジ**: 画面ヘッダーおよび同期モーダルに常時インジケーターを表示。
  - 🟢 **同期完了** (最新状態をクラウドと保持)
  - 🟡 **同期中…** (データ送受信中)
  - 🔴 **オフライン保存** (端末内LocalStorageに安全保護)
* **LWW（Last-Write-Wins）競合防止**: MacとiPhoneの執筆タイムスタンプをミリ秒単位で比較し、電波復帰時の先祖返り・上書き消失を完全に防止。

### 8. 🎯 部分推敲（エディタ選択範囲のみのピンポイント推敲）
* **選択テキストのみのAI推敲**: エディタ内で特定の段落やセリフを選択すると、「選択範囲推敲中」バッジが点灯。
* **範囲ピンポイント置換**: 推敲モーダルで「反映」を押すと、選択した範囲だけを推敲後テキストへ正確に差し替え。

### 9. 📑 長文執筆用アウトライン（目次ナビ）表示
* **見出し（#、##、第○章等）の自動抽出**: エディタ内の見出し構造を自動解析し、折りたたみ式ドロワーにリアルタイム表示。
* **ワンクリックジャンプ**: 該当の章・節をクリックするだけで、エディタの該当行へ瞬時にスクロール＆フォーカス。

## 📱 iPhone / iPad でのホーム画面追加（PWA対応）

1. iPhoneのSafariで `https://othaway-usamafty-rgb.github.io/tamaki-studio/` を開く。
2. 画面下部の中央にある「共有」アイコン（四角から矢印が飛び出ているアイコン）をタップ。
3. メニューから「**ホーム画面に追加**」を選択。
4. ホーム画面に専用のTamaki Studioアイコンが追加され、URLバーのない全画面ネイティブアプリ風コックピットとして起動できます。オフラインでも原稿作成・保存・閲覧が可能です。
