# Tamaki Studio v2.0 Pro（たまきぱずず専属執筆工房）

筆者（たまきぱずず氏）特有の文体・思考様式（鋭いメタ認知、高い解像度、宇宙世紀原理主義、生々しいリアリズム、軽妙なオチ）を完全再現するための専用執筆支援Webアプリケーションです。

v2.0では、実際の過去原稿データ（ガンダム52話打ち切りIF論考、テキサスコロニー建造考証、散財エッセイ、小説）を解析・注入し、**「原稿ドロップ読み込み」「語録・思考トリガーパレット」「リアルタイム文体シンクロ率チェッカー」**が大幅に進化しました。

---

## 🚀 起動方法

### 方法1: ブラウザで直接開く（一番かんたん）
1. `tamaki-studio/index.html` ファイルをダブルクリック（またはブラウザにドラッグ＆ドロップ）して開くだけで即座に使用できます。

### 方法2: ローカルWebサーバーで開く（おすすめ）
ターミナルで本ディレクトリ（`tamaki-studio`）に移動し、以下のコマンドを実行します：

```bash
# Python 3 の場合
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

## ✨ v2.0 主な新機能と使い方

### 1. 📄 過去原稿・メモのドラッグ＆ドロップ読み込み（New!）
* 画面上部のドロップゾーンにお手持ちの `.md` や `.txt` 原稿ファイルをドロップするだけ。
* **文体お手本への直結**: 読み込んだ原稿が自動的にAIの「最優先お手本（Reference）」としてプロンプトに注入されます。
* **フォームへ展開**: 原稿の見出しや内容を解析し、各入力欄（テーマ・ディテール・考察・オチ）へ自動展開できます。

### 2. 🧩 たまきぱずず語録・思考トリガーパレット（New!）
* 「……お気づきでしょうか」「完全に掌の上」「安心感を買っているだけ」「老害オタクの夜戯言」「メガ・イマジニアリング」「冷徹なメタ認知」など、特有のキラーフレーズをワンクリックで入力欄に挿入できます。

### 3. 📊 リアルタイム「たまきぱずず度（文体シンクロ率）」チェッカー（New!）
* 生成された文章やエディタ内の執筆文をリアルタイム診断：
  * **総合シンクロ率（%）**
  * **4大要素スコア**: 「🎭 メタ認知・自虐」「🔍 五感・具体性」「⚡ リズム・改行」「🍃 オチのキレ」
  * **具体的アドバイス & AI臭さ警告**: 「AI特有の綺麗事まとめを検知」「オチに自虐ツッコミを足すと95%超え」など即時フィードバック。

### 4. 🎯 実際の原稿を内蔵した超高精度 Few-Shot プリセット
* 例文セレクターから代表作をワンタッチ読込：
  * ☕ **エッセイ**: 真夏の酷暑ゴルフ散財 / 最新ガジェット沼と自己正当化
  * 🤖 **ガンダム・論考**: 全52話打ち切りIFとトミノメモ / テキサスコロニー建造計画とメガ・イマジニアリング / 復讐のレクイエム
  * 📖 **小説・官能**: 雨の夜のオフィス密会 / 車内の密室と理性のグラデーション

### 5. 2つの生成方法
1. **「プロンプトを合成・コピー」ボタン**:
   - ChatGPT / Claude / Gemini のWeb版に貼り付けて使用できます。
2. **「AIで筆者風に直接執筆する」ボタン**:
   - Google Gemini API キーを登録すると、アプリ画面内で直接執筆・生成されます。

### 6. ワンクリック推敲アシスト
* 「🔥 もっと自虐・ツッコミ追加」「🔍 生々しい具体性をアップ」「🍃 オチを軽やかに着地」「✨ AI臭さを徹底除去」
