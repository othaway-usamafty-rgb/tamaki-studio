# Tamaki Studio v2.1 Pro（たまきぱずず専属執筆工房）

筆者（たまきぱずず氏）特有の文体・思考様式（鋭いメタ認知、高い解像度、宇宙世紀原理主義、思考の迷走プロセス、生々しい本音、軽妙なオチ）を完全再現するための専用執筆支援Webアプリケーションです。

v2.1では、ChatGPTおよびClaudeによる査読フィードバックを反映し、**「思考の揺れ・迷走度チューニング」「ファクトチェック＆AI造語警告」「妄想境界宣言」「論文調の完全排除」**が新設・強化されました。

---

## 🚀 起動方法

### 方法1: ブラウザで直接開く（一番かんたん）
1. `tamaki-studio/index.html` ファイルをダブルクリック（またはブラウザにドラッグ＆ドロップ）して開くだけで即座に使用できます。

### 方法2: ローカルWebサーバーで開く（おすすめ）
ターミナルで本ディレクトリ（`tamaki-studio`）に移動し、以下のコマンドを実行します：

```bash
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

## ✨ v2.1 主な新機能と特徴

### 1. 🌪️ 思考の揺れ・迷走度チューニング（New!）
* AIの「綺麗にまとまりすぎる論文調」を崩し、「調べる → 違和感 → 仮説 → いや待てよと疑う → 妄想が加速する」というオタク特有の思考の葛藤・二転三転のプロセスを再現します。

### 2. 🔍 ファクトチェック＆AI造語（ハルシネーション）アラート（New!）
* 年月日（ガンプラ発売日：1980年7月19日等）や企業名、曖昧な推測（「推察されます」等）、「大曲律」のようなAI誤変換・造語を自動検知して注意喚起します。

### 3. 🎯 ワンクリック推敲アシスト（進化版）
* 🌪️ **「思考の揺れ・脱線を追加」**: 一直線な論理に「いや、待てよ」「そもそも〜」という寄り道を挟む。
* 🎯 **「妄想境界を宣言」**: 「……さて、ここからは完全に私の妄想ですが」を挿入し、考察への没入感を高める。
* 💥 **「原理主義の毒気を注入」**: 尖ったオールドタイプの偏愛・毒舌フレーズを挿入。
* ✨ **「AI臭さ・論文調を除去」**: 「〜と考えられます」等の硬い表現を「〜だと思うんですよ」等の口語に自動変換。

### 4. 📊 リアルタイム「たまきぱずず度（文体シンクロ率）」チェッカー
* **総合シンクロ率（%）**
* **4大要素スコア**: 「🎭 メタ認知・自虐」「🌪️ 思考の揺れ・迷走」「🔍 五感・具体性」「🍃 オチのキレ」
* **論文調・AI臭さ検出**: 抽象比喩の三連発や教科書的まとめを減点・アドバイス。

### 5. 📄 過去原稿・メモのドラッグ＆ドロップ読み込み
* 手持ちの `.md` / `.txt` をドロップすると、プロンプトの最優先お手本（Reference）として自動注入。
