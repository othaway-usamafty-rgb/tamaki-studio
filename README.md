## 🚀 起動・アクセス方法

### 方法1: Web（GitHub Pages）で開く（おすすめ）
ブラウザで以下にアクセスします：
**[https://othaway-usamafty-rgb.github.io/tamaki-studio/](https://othaway-usamafty-rgb.github.io/tamaki-studio/)**

### 方法2: ローカルWebサーバーで開く
ターミナルで本ディレクトリ（`tamaki-studio`）に移動し、以下のコマンドを実行します：

```bash
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

## ✨ v3.0.2 Ultra 主な新機能と特徴

### 1. ⏱️ 選択式・自動保存＆Mac ↔ iPhone クラウド同期（New in v3.0.2!）
* 自動保存・同期の周期（5秒 / 10秒 / 30秒 / 1分 / 5分 / オフ）をユーザーが自由選択可能。
* Macで書いた続きをiPhoneでそのまま再開でき、同期漏れを防ぎます。

### 2. 🟢 ChatGPT推敲バトンタッチ連携
* Geminiで生成したベース原稿を、特製「皮肉屋でサブカル愛ある優秀な編集者」プロンプトで包んでワンタップコピー。ChatGPT（無料枠）で仕上げの伴走・推敲が行えます。

### 3. 🚽 便所の落書き（無機質デトックス空間）
* 自意識の目詰まりを排除し、感情や雑感をそのまま吐き出せるシンプルなテキスト空間。「AIスタジオへ送る」で執筆フォームへ一気展開。

### 4. 🛡️ コンプラ・身バレ アラート
* 特定の車種名やホテル名、住所などの特定固有名詞を自動検知して注意喚起。「⚠️生々しすぎます」アラートで安全な表現へと置換できます。
