# Tamaki Studio（たまきぱずず執筆工房）

筆者（たまきぱずず氏）特有の文体・思考様式（鋭いメタ認知、高い解像度、宇宙世紀原理主義、生々しいリアリズム、軽妙なオチ）を完全再現するための専用執筆支援Webアプリケーションです。

---

## 🚀 起動方法

### 方法1: ブラウザで直接開く（一番かんたん）
1. `tamaki-studio/index.html` ファイルをダブルクリック（またはブラウザにドラッグ＆ドロップ）して開くだけで即座に使用できます。

### 方法2: ローカルWebサーバーで開く（おすすめ）
ターミナルで本ディレクトリ（`tamaki-studio`）に移動し、以下のコマンドを実行します：

```bash
# Python 3 の場合
python3 -m http.server 8080
```
ブラウザで `http://localhost:8080` を開きます。

## ✨ 主な機能と使い方

### 1. 3つの執筆ジャンル選択
* ☕ **エッセイ・コラム**: 日常の体験、最新ツール・ギアへの散財、鋭い自己客観視と軽妙なオチ。
* 🤖 **ガンダム・サブカル論考**: 宇宙世紀原理主義、看板（IP）と本質の峻別、商業構造の客観的分析、SF的リアリズム。
* 📖 **小説・官能描写**: 五感・身体感覚の解像度、情欲と冷徹なメタ認知の同居、生々しい台詞。

### 2. 「例文を読み込む」ボタン
* 画面右上の「例文を読み込む」を押すと、各モードに応じた質の高いテスト用インプット（真夏の酷暑ゴルフ、ガンダム新作の違和感、雨の夜のオフィス）が自動入力されます。

### 3. たまきぱずず度 チューニング
* **メタ認知・ツッコミ度**: `控えめ` ↔ `標準` ↔ `全開（自虐・迷い多め）`
* **ディテール解像度**: `標準` ↔ `超高解像度（生々しい五感・固有名詞）`
* **文章リズム・テンポ**: `スマホ短文改行` ↔ `標準` ↔ `重厚`
* **AI臭さ完全排除モード**: 「いかがでしたでしょうか」などのテンプレ表現をAIに厳禁指定。

### 4. 2つの生成方法
1. **「プロンプトを合成・コピー」ボタン**:
   - APIキー不要。普段お使いの ChatGPT / Claude / Gemini のWeb版に貼り付けて使用できます。
2. **「AIで筆者風に直接執筆する」ボタン**:
   - 右上の「API連携設定」から Google Gemini API キーを登録すると、アプリ画面内で直接執筆・生成されます。

### 5. 推敲アシスト & AI臭さチェッカー
* 「いかがでしたでしょうか」などのAI特有の紋切り型表現を自動検出して警告。
* ワンクリック推敲ボタン（「🔥 もっと自虐追加」「🔍 生々しい具体性アップ」「🍃 オチを軽やかに」）で即座にリライト。

### 6. 保存・エクスポート
* **「文章をコピー」**: noteにそのまま貼れる形式でクリップボードにコピー。
* **「.md 保存」**: Markdownファイルとして直接ダウンロード。
* **「履歴」**: 過去に生成した文章を最大20件までローカル保存・いつでも復元可能。
