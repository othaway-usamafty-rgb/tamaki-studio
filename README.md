## ✨ v4.0.0 Ultra 主な新機能と特徴

### 1. 🔍 高速ローカル校正インスペクター（New in v4.0!）
* **API不要・完全ローカル・0秒検知**: テキストを入力するそばから自動で文章を解析。
* **日本語の代表的誤用**: 「的を得る（→的を射る）」「敷居が高い（→ハードルが高い）」「足をすくわれる（→足元をすくわれる）」「汚名挽回（→汚名返上）」等を検知。
* **表記揺れチェック**: 同一記事内での「Web／ウェブ」「ユーザー／ユーザ」「行う／行なう」等の混在を自動指摘。
* **悪文・リズムの引っ掛かり**: 「見れる・食べれる（ら抜き言葉）」「〜の〜の〜の（助詞3連続）」「1文110文字超の長文警告」をハイライト。
* **ワンタップ修正・一括修正**: 指摘カードの「修正」ボタンや「一括修正」で即座にエディタへ反映。

### 2. 🪄 たまき節 推敲スタジオ＆Diff差分比較（New in v4.0!）
* **持ち味を殺さない本格推敲**: 一般的なAIが消してしまいがちな「鋭い自虐・メタ認知」「思考の迷走（脱線）」「生々しい五感解像度」「軽妙なオチ」を徹底的に活かしつつ、冗長な贅肉だけを削ぎ落とします。
* **差分（Diff）可視化ビューア**: 修正前後のテキストを赤（削除）と緑（追加）でハイライト。どこがどうブラッシュアップされたが一目で分かります。
* **編集者メモと一発反映**: 編集者からの推敲意図・アドバイスを確認し、「この推敲案をエディタに反映」でワンタップ置換（元原稿は履歴に安全にバックアップ保存）。
* **AI精密校正モード**: 文脈に沿った誤字脱字や構文の客観的校正も選択可能。

### 3. 🧩 語録・思考トリガーの1行選択窓化（New in v4.0!）
* 画面を大きく圧迫していた大量の語録ボタン群を、**高さ約36pxの1行ドロップダウン選択窓**に刷新。
* 画面占有率を**95%削減**し、執筆フォームへのアクセス性とスクロール性を劇的に改善しました。

### 4. ⏱️ 選択式・自動保存＆Mac ↔ iPhone クラウド同期
* 自動保存・同期の周期（5秒 / 10秒 / 30秒 / 1分 / 5分 / オフ）をユーザーが自由選択可能。
* Macで書いた続きをiPhoneでそのまま再開でき、同期漏れを防ぎます。

### 5. 🟢 ChatGPT推敲バトンタッチ連携
* Geminiで生成したベース原稿を、特製「皮肉屋でサブカル愛ある優秀な編集者」プロンプト（校正・推敲指針付き）で包んでワンタップコピー。ChatGPT（無料枠）で伴走・推敲が行えます。

### 6. 🚽 便所の落書き（無機質デトックス空間）
* 自意識の目詰まりを排除し、感情や雑感をそのまま吐き出せるシンプルなテキスト空間。「AIスタジオへ送る」で執筆フォームへ一気展開。
